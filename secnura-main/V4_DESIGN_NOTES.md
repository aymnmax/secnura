# Secnura Website — V4 Design Update

## Changes
- Replaced the hero security dashboard/logo scan visual with a clean **service-first showcase**.
- Removed the shield/logo from the centre of the scanning panel.
- The hero panel now displays all **8 Secnura cybersecurity services** as readable, interactive service banners.
- Added service icons, numbering, concise descriptions and direct links to the Services section.
- Added a quiet security workflow footer: Assess → Protect → Detect → Respond → Recover.
- Reworked the **Our Approach** section into a stronger five-step desktop layout with consistent spacing, numbering, icon treatment and connecting arrows.
- Improved mobile responsiveness by stacking service banners and approach steps cleanly.

## Brand direction
The design keeps the Secnura navy + cyan identity while reducing visual noise. The goal is to let a first-time visitor understand what Secnura does within a few seconds.
