# Secnura Website V3

This version focuses on a calmer, more user-friendly first impression while retaining the Secnura visual identity.

## Hero redesign
- Replaced the crowded live-security dashboard treatment with a focused Secnura security showcase.
- Kept subtle scanning/orbit motion around the Secnura shield.
- Added a clear, human headline and simple primary/secondary calls to action.
- Added an in-hero service showcase for VAPT, SOC, AppSec and Incident Response.
- Kept the full service matrix further down the page, including all eight existing services.

## Existing sections retained
- Our Story
- Full cybersecurity services list
- Assess → Protect → Detect → Respond → Recover approach
- Free 2026 cybersecurity awareness training campaign
- Why Secnura
- Contact/enquiry form

## Run locally

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run start
```
