# Secnura V6 Design Notes

- Reworked the hero service showcase into a compact, premium service spotlight rather than a dashboard.
- Removed the lower `ASSESS / PROTECT / DETECT / RESPOND / RECOVER` footer row from the hero showcase.
- Removed the redundant `SECNURA / SECURITY SERVICES` + `SERVICES AVAILABLE` dashboard framing from the visual treatment.
- Added a lightweight human cybersecurity advisor illustration with a speech bubble to make the section more approachable and human.
- Kept the one-service-at-a-time carousel and reduced the rotation interval to 2.2 seconds.
- Preserved click navigation and pointer/swipe navigation for mobile.
- Optimized the service spotlight for compact desktop and mobile layouts.
- Existing 8 Secnura services are still driven by `src/features/services/data.ts`.
