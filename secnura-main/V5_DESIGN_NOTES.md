# Secnura Website V5 — UX Update

## What changed
- Replaced the crowded 8-card hero service grid with a single focused service carousel.
- Hero service rotates automatically every 2.6 seconds.
- Added direct service navigation/progress bars so visitors can jump to any service.
- Added pointer/touch swipe behavior so mobile visitors can slide one service at a time.
- Removed the center shield/logo from the scanning/service showcase.
- Replaced the previous Assess / Protect / Detect / Respond / Recover rail with an outcome-led section called “The Secnura Difference”.
- The new section focuses on five business outcomes: See exposure, Reduce risk, Stay alert, Act fast, Build resilience.
- Kept the existing service catalogue, 2026 free cybersecurity awareness training campaign, story, positioning, contact form and visual identity.

## Run locally

```bash
npm install
npm run dev
```

The project is a Next.js application.
